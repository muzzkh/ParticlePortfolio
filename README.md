# Particle Portfolio

Resume site for **Muzzamil Khan**, served at
[www.muzzamilkhan.com](https://www.muzzamilkhan.com). It has two pages:

- **`/` — the desert.** An interactive résumé built with three.js: walk a
  procedurally generated desert and read each chapter of the résumé from the
  waystones (glowing monoliths) along the road. The code is vendored from
  [muzzkh/arrakis](https://github.com/muzzkh/arrakis); see
  [Updating the desert](#updating-the-desert).
- **`/classic/` — the plain version.** A clean React + TypeScript resume card
  with an interactive particle field that drifts behind it and deflects off it.
  Browsers without WebGL are sent here automatically.

Both pages read the same data from `src/data/resume.ts`, and the PDF lives at
`public/Muzzamil_Khan_Resume.pdf`.

Built with React + TypeScript + three.js + Vite.

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default `http://localhost:5173`) for the
desert, or `/classic/` for the plain page.

To build for production:

```bash
npm run build
npm run preview
```

## Adding new content

The site is intentionally data-driven so day-to-day updates don't require
touching component code. Everything in `src/data/resume.ts` shows up on both
pages: each experience, education entry and project becomes a waystone in the
desert (newest first along the road), and the skills groups become the last
one. `profile.headline` is the line shown above the name on the desert's intro
screen.

To replace the PDF, overwrite `public/Muzzamil_Khan_Resume.pdf`.

### Add a new tab

1. Create a new component in `src/components/sections/` that returns a `<div className="section">…</div>`.
2. Register it in `src/data/tabs.ts`:

   ```ts
   import Awards from '../components/sections/Awards'

   export const tabs: Tab[] = [
     // …existing tabs
     { id: 'awards', label: 'Awards', Component: Awards },
   ]
   ```

That's it — the tab nav, panel routing, animations, and persisted "last
selected tab" state all pick it up automatically.

### Add a new project

Open `src/data/resume.ts` and append to `projects`:

```ts
export const projects: ProjectItem[] = [
  {
    name: 'My new project',
    description: 'One-sentence summary of what it is and the impact.',
    href: 'https://example.com',
    repo: 'https://github.com/your/repo',
    stack: ['React', 'TypeScript'],
    highlight: true,
  },
]
```

The Projects tab will render it in the grid automatically — no JSX changes
needed. The empty-state message disappears as soon as the array is non-empty,
and the project gets its own waystone in the desert.

### Add or change a contact link

Edit the `profile.links` array in `src/data/resume.ts`. Supported icons:
`mail`, `linkedin`, `github`, `globe`, `external`.

## How the particle interaction works

`ParticleField.tsx` renders a fixed full-viewport `<canvas>` and runs a small
physics loop on `requestAnimationFrame`:

- Particles drift slowly with a damped velocity cap.
- They're gently repelled by the cursor within `mouseRadius` px.
- They deflect off the bounding rectangle of the resume card (passed in via
  `obstacleRef`) so the card looks like a physical object the particles flow
  around.
- Nearby particles draw faint connecting lines for a constellation effect.

The card's bounding rect is updated on resize, scroll, and via a
`ResizeObserver`, so the obstacle stays in sync as content (and tabs) change.

## Updating the desert

The desert's source of truth is [muzzkh/arrakis](https://github.com/muzzkh/arrakis).
Make changes there, then pull them in from a checkout next to this one:

```bash
scripts/sync-desert.sh ../arrakis
```

The script replaces `src/desert/` and the root `index.html` (and copies the
favicon), but keeps `src/desert/resume/content.js`, which points the desert at
`src/data/resume.ts` and at this site's PDF and `/classic/` page.

## Deploying

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds both pages
into `dist/` and publishes it to the `gh-pages` branch with the `CNAME` for
www.muzzamilkhan.com. No settings change is needed for the desert: it is just
the new `index.html`.
