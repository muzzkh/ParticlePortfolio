# Particle Portfolio

The deploy repo for **Muzzamil Khan**'s site,
[www.muzzamilkhan.com](https://www.muzzamilkhan.com): an interactive résumé
built with three.js. Visitors walk a procedurally generated desert and read
each chapter of the résumé from the waystones (glowing monoliths) along the
road. The desert itself is developed in
[muzzkh/arrakis](https://github.com/muzzkh/arrakis) and vendored here; see
[Updating the desert](#updating-the-desert).

Browsers without WebGL get the intro screen with the PDF and contact links.

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default `http://localhost:5173`).

To build for production:

```bash
npm run build
npm run preview
```

## Project structure

```
index.html                 # The page (generated by scripts/sync-desert.sh)
public/
  Muzzamil_Khan_Resume.pdf # Linked from the intro screen and the résumé index
  waystone.svg             # Favicon (synced from arrakis)
scripts/
  sync-desert.sh           # Pulls the desert in from a muzzkh/arrakis checkout
src/
  data/
    resume.ts              # All resume content lives here
  desert/                  # Vendored from muzzkh/arrakis, don't edit here
    main.js                # Scene, game loop, résumé orchestration
    waystones.js           # The monoliths and project landing pads, and their layout
    ornithopter.js         # The ornithopter on the project pad
    codex.js               # Résumé index, dossier card, floating labels
    arcade/                # The arcade (P) and its three mini games
    multiplayer.js         # Other visitors in the same world (peer-to-peer)
    atomics.js             # Atomics strike and launch-code check
    launchpad.js           # Launch keypad
    resume/content.js      # Re-exports src/data/resume.ts (kept across syncs)
    …                      # terrain, sandworm, walker, particles, audio
```

## Updating the résumé

Edit `src/data/resume.ts`. Each experience and education entry becomes a
waystone (newest first along the road) and the skill groups become the last
one. Each project gets a landing pad off the other way, with the 3D model named
in its `model` field (`'ornithopter'`, or none for a cargo pod).
`profile.headline` is the line shown above the name on the intro screen.

To replace the PDF, overwrite `public/Muzzamil_Khan_Resume.pdf`.

## Updating the desert

The desert's source of truth is [muzzkh/arrakis](https://github.com/muzzkh/arrakis).
Make changes there, then pull them in from a checkout next to this one:

```bash
scripts/sync-desert.sh ../arrakis
```

The script replaces `src/desert/` and the root `index.html` (and copies the
favicon), but keeps `src/desert/resume/content.js`, which points the desert at
`src/data/resume.ts` and at this site's PDF.

## Deploying

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site
into `dist/` and publishes it to the `gh-pages` branch with the `CNAME` for
www.muzzamilkhan.com.

The previous React particle résumé was removed in favour of the desert; it is
in the git history (last present at `d2f56bd`).
